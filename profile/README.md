# SoybeanJS

> Elegant admin systems, UI foundations, and modern frontend tooling.
> 优雅的后台系统、UI 基础设施与现代前端工程化。
</div>

SoybeanJS is an open-source team focused on building modern admin solutions, design-oriented UI foundations, full-stack frameworks, and developer tooling for productive web teams — now exploring AI-agent-friendly development.

## Capabilities

- **Frontend**: Vue 3, React, Solid, Svelte, Astro
- **SSR**: Nuxt, Next, SolidStart, SvelteKit, hono-ssr
- **Backend**: Node.js / Bun / Deno, Hono, Nitro, Cloudflare Workers
- **Build**: Vite, rolldown-vite, unbuild, tsup, tsdown
- **Code Quality**: eslint-config, oxc-config, simple-git-hooks, lint-staged
- **Visualization**: AntV, ECharts, Chart.js, D3, Three.js
- **Cross-platform**: React Native, UniApp, Ionic, Tauri, Electron
