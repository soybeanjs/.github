### UI System — soybean-ui

The shadcn/ui approach for Vue: headless primitives with ready-to-use styled wrappers, plus a complete theme engine.

- [soybean-ui](https://github.com/soybeanjs/soybean-ui) — headless primitives + styled wrappers for Vue3
- [shadcn-theme](https://github.com/soybeanjs/shadcn-theme) — theme generator with dynamic CSS variables & light/dark mode
- [unocss-shadcn](https://github.com/soybeanjs/unocss-shadcn) — shadcn-style UnoCSS preset
- [cva](https://github.com/soybeanjs/cva) — Class Variance Authority for Vue

### Full-stack Framework — ubean

- [ubean](https://github.com/soybeanjs/ubean) — **The full-stack Vue framework for Vite**: SSR, file-based routing, type-safe request layer
- [hono-ssr](https://github.com/soybeanjs/hono-ssr) — SSR with Vite and Hono
- [fetch](https://github.com/soybeanjs/fetch) — lightweight, type-safe HTTP client on native fetch
- [soybean-unify](https://github.com/soybeanjs/soybean-unify) — next-gen admin template based on SoybeanUI + VitePlus
